# MIN의 문장 — 현업 보고서 문체 가이드

MIN이 직접 쓴 캠페인 제안서 3건(교육·건강기능식품·OTT)에서 뽑은 작문 방식이다.
리포트·공정 로그·검수 의견 등 사람이 읽는 모든 문장에 적용한다.
목표는 하나. **처음 읽는 실무자가 한 번에 알아듣고, 바로 회의에 들고 갈 수 있는 글.**

---

## 1. MIN은 이렇게 쓴다

### 1) 질문으로 열고, 예상을 뒤집어 답한다
- 독자가 품을 질문을 먼저 던지고, 짧게 답한다.
- 예: "경쟁자로 가득 찬 시장에서 우리만의 자리를 찾는 방법은? — 없습니다. 그럴 필요가."
- 예: "굳이 공부에 탭을?"

### 2) 한 줄에 생각 하나. 줄바꿈이 리듬이다
- 긴 문장 하나보다 짧은 줄 세 개.
- 개조식 줄은 명사형으로 끝내도 된다: "~필요", "~상황", "~가능", "~한계".
- 설명 줄과 결론 줄을 섞지 않는다. 결론 줄은 따로 떼어 짧게 못 박는다.
  - 예: "우리는 콘텐츠를 넘어, 미디어입니다."

### 3) 추상어 대신 손에 잡히는 비유
- 개념을 설명하지 말고 장면으로 보여 준다.
- 예: 겉모습만 비슷한 경쟁 → "갈색을 띠는 카페인 음료" (커피와 콜라는 경쟁자가 아니다)
- 예: 구독을 쉽게 바꾸는 소비자 → "마치 채널을 돌리듯"
- 예: 의미 없는 기능 경쟁 → "도토리 키재기"

### 4) 대구로 대비한다
- "저들은 팔릴 만한 것을 만들지만, 우리는 시대의 모습을 반영합니다."
- "효율을 지향하되 공감을 사야 하고, 구매를 유발하되 로열티가 따라야 한다."
- "콘텐츠는 '상품의 선택', 구독은 '생활의 선택'."

### 5) 남의 말과 숫자로 증명한다
- 타깃의 실제 목소리를 그대로 인용한다. (예: 학부모 커뮤니티 글 "매일 인강하라 잔소리하고… 일주일이 일년 같아요")
- 숫자는 정확하게, 출처는 바로 옆에. (예: "검색 결과 196,857개 — 네이버 쇼핑, 프리미엄 영양제")
- 논문·조사 인용은 한 줄 요지 + 출처. 권위 장식으로 쓰지 않는다.

### 6) 솔직한 구어 한 방
- 전체는 담백하게, 결정적인 순간에 말하듯 한 줄.
- 예: "도토리 키재기는 하지 맙시다."
- 예: 괄호 속 촌평 "(넷플릭스와 다르다고 말하면서 넷플릭스 따라 하는 중)"
- 남발하지 않는다. 섹션당 한 번이면 충분하다.

### 7) 이정표는 짧은 라벨로
- 구간마다 PROBLEM / INSIGHT / CONCEPT / ACTION 같은 짧은 라벨을 세운다.
- 라벨 아래 첫 줄이 그 구간의 결론이다.

### 8) 고유명사·숫자·단위로 말한다
- "다양한 채널" ✕ → "인스타그램·맘카페·올리브영 매장" ○
- "합리적인 비용" ✕ → "주 600만 원, 성수역 도보 5분" ○

## 2. AI 티 나는 말 — 쓰지 않는다

### 연결 상투구
결론부터 말하면 · 핵심은 ~입니다 · ~라는 점에서 · ~을 통해 · 이를 바탕으로 · 이를 통해 · 다시 말해 · 나아가 · 아울러 · 뿐만 아니라 · ~에 있어서 · 이러한 맥락에서 · 궁극적으로 · 요컨대

### 문장 꼬리
~하는 것이 중요합니다 · ~라고 할 수 있습니다 · ~로 판단됩니다 · ~이 요구됩니다 · ~이 기대됩니다 · ~할 필요가 있습니다 · ~에 기여할 것입니다 · ~의 역할을 합니다

### 한자어·추상어 → 일상어
| 쓰지 말 것 | 이렇게 |
|---|---|
| 활용하다 | 쓰다 |
| 제고하다 | 높이다 |
| 도모하다 · 꾀하다 | (무엇을 하는지 동사로) |
| 구축하다 | 만들다 · 세우다 |
| 극대화하다 | 최대한 늘리다 / 숫자로 |
| 최적화하다 | 맞추다 |
| 강화하다 | 키우다 · 늘리다 |
| 확보하다 | 얻다 · 잡다 · 모으다 |
| 수립하다 | 세우다 · 짜다 |
| 영위하다 · 향유하다 | 누리다 · 쓰다 |
| 측면에서 · 관점에서 · 차원에서 | ~로 보면 / 빼기 |
| 요소 · 요인 | (구체적인 이름) |
| 다양한 | (실제로 나열) |
| 효과적인 · 효율적인 | (무엇이 얼마나) |
| 유의미한 · 실질적인 | (얼마나) |
| 본질적 · 근본적 · 궁극적 | 빼거나, 무엇이 본질인지 바로 쓰기 |
| 전략적 · 체계적 · 다각적 · 선제적 · 총체적 | 빼기 |
| 혁신적 · 획기적 | 무엇이 새로운지 쓰기 |
| 시너지 | 무엇이 무엇을 키우는지 |
| 인사이트를 도출하다 | 알아낸 것은 ~ |
| 니즈를 충족하다 | 원하는 걸 준다 |
| 해당 ~ | 이 ~ / 그 ~ |

현업 용어(타깃, 니즈, 포지셔닝, USP, RTB, CAC, 바이럴, 리텐션)는 써도 된다. 실무자가 실제로 쓰는 말이기 때문이다.
금지 대상은 **회의에서 아무도 소리 내어 말하지 않는 말**이다.

### AI 리듬
- 모든 걸 3개씩 나열하는 습관. 2개면 2개, 5개면 5개.
- "단순히 A가 아니라 B" 반복. 한 문서에 한 번까지.
- 문단 끝마다 앞 내용을 되풀이하는 요약 문장.
- 콜론(:)과 줄표(—)로 문장을 이어 붙이기.
- 같은 말을 다른 단어로 두 번 하기.

## 3. 고쳐 쓰기 예시

**AI 문장**
> 본 전략은 타깃 고객의 니즈를 효과적으로 충족시킴으로써 브랜드 인지도를 제고하고, 이를 통해 지속 가능한 성장 기반을 구축하는 데 기여할 것으로 판단됩니다.

**MIN 문장**
> 1~2인 가구는 "오늘 뭐 먹지"를 매일 고민한다.
> 이 고민을 대신 끝내 주면, 브랜드를 기억한다.
> 첫 3개월 목표는 재구매율 40%.

**AI 문장**
> 경쟁 환경이 심화되는 가운데, 차별화된 가치 제안을 통해 시장 내 독보적 포지션을 확보하는 것이 중요합니다.

**MIN 문장**
> 경쟁사와 같은 줄에 서는 순간 진다.
> 비교되지 않을 자리를 고른다 — 메뉴 수가 아니라 "결정 대행".

## 4. 리포트 형식

- 맨 위 요약은 3~5줄. 결론, 이유, 할 일 순서.
- 섹션은 라벨 + 결론 한 줄 + 근거 목록.
- 강조(**굵게**)는 문단당 하나. 인용(>)은 실제 카피·원문·타깃 목소리에만.
- 표는 비교할 때만. 문장으로 충분하면 표를 만들지 않는다.
